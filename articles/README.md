# 初期記事

5つの記事型と5つの読者目的を確かめるための**本文草稿**。すべて`status: draft`であり、公開済み・実証済みとは扱わない。

| 読者の目的 | 記事 | 型 | 確認したいこと |
| --- | --- | --- | --- |
| 選ぶ | [月額100ドルのAI開発予算](ai-dev-budget/article.md) | 判断 | 具体的な価格・上限・利用実績が揃えば推奨を確定できるか |
| 活用 | [複数AIエージェントの並列化](parallel-agents/article.md) | 実験 | 単独／並列の同条件実験と生ログが必要 |
| 構築 | [miseとdotfilesで環境再現](reproduce-ai-dev-env/article.md) | 手順 | 新しい端末でE2E再現できるか |
| 理解 | [MCPとCLIの使い分け](mcp-or-cli/article.md) | 解説 | 公式仕様と実例だけで判断できるか |
| 追う・見通す | [AIツールの価格・利用上限](ai-tool-limits/article.md) | 見解 | 著者の見解と公式事実を区別できるか |

各記事には**独自の説明用SVG図版**を1枚置いた。これらは模式図であり、実測グラフや実機スクリーンショットを代用する証拠ではない。

## 置き方

```text
articles/<slug>/
├── article.md       # タイトル・メタデータ・本文
└── assets/
    └── <figure>.svg # 編集可能な模式図
```

`slug` は分類・入口とは無関係の恒久識別子。掲載先を変えても本文をコピーして二重管理しない。

## 公開前に確認すること

- 第一文が対象読者の問いに答え、事実と判断が区別されている。
- 事実の根拠URL・対象時点・実験条件が揃っている。
- 図版が本文の意味に役立ち、altテキストと説明がある。
- `verified_at: null` のまま「検証済み」と表示しない。
- 著者の実測値・スクリーンショットを要求する記事は、得られるまで`draft`のままにする。
