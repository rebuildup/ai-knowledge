# 文章制作に使うSkills

**文章の選択と構造はwriting-discipline、日本語の初稿はnatural-japanese、最終的な意味保持の推敲はyomiyasu。** 同じ役割のスキルを闇雲に重ねない。

| 段階 | スキル | 何を判断するか |
| --- | --- | --- |
| 記事の設計 | [writing-discipline](../.agents/skills/writing-discipline/SKILL.md) | 読者、問い、言い切るべき答え、不要な説明 |
| 初稿・構造 | [natural-japanese](../.agents/skills/natural-japanese/SKILL.md) | 日本語のつながり、冗長さ、機械的な見出し、翻訳調 |
| 推敲 | [yomiyasu](../.agents/skills/yomiyasu/SKILL.md) | 元の事実・主張・断定の強さを保ち、不自然な表現を直す |

**スキル同士の指示が衝突した場合は[このリポジトリの執筆方針](執筆方針.md)と元資料の正確性を優先**する。自然さの検査が出した警告は「修正候補」であり自動で不合格にするものではない。

## 置き場所

`.agents/skills/`に実際のSkillとそのスクリプト・参照資料を保存。Claude Codeには`.claude/skills/`の入口から実体を読ませる。AIエージェント共通の手順はルート[AGENTS.md](../AGENTS.md)に記載。

```text
.agents/skills/writing-discipline/
.agents/skills/natural-japanese/
.agents/skills/yomiyasu/
.claude/skills/                     # 各Skillへの入口
```

収録版（アップデート時は差分確認を行う）：

- writing-discipline、natural-japanese： [rebuildup/writing-skills @ 7ba09d1](https://github.com/rebuildup/writing-skills/tree/7ba09d1886dd52d6d876d58e198f83f9127bc258/skills)
- yomiyasu：[nanaism/yomiyasu @ 84e1f5b](https://github.com/nanaism/yomiyasu/tree/84e1f5b15e497538fcfe19ab7e9c6f6d138f19ff/skills/yomiyasu)

使用可能なランタイム文書・PythonスクリプトをMIT表記とともに収録。宣伝画像・デモ用テスト群・プラグインマニフェストは同梱していない。yomiyasuの利用は現行[公式手順](https://github.com/nanaism/yomiyasu)も参照。別の版への更新は、勝手な追従ではなくPRで確認する。

## 最低限の検査

```bash
python3 scripts/editorial_check.py  # 記事メタデータ・図版の参照先を検査
python3 .agents/skills/yomiyasu/scripts/yomiyasu_lint.py --help
# 形態素解析系の診断はuv等で依存関係を用意してから実行する
```

品質の最終判断は**記事本文の推敲・見出しの具体性・根拠に合った画像の有無**で行う。ツール導入やlintの実行だけでは記事は完成しない。
