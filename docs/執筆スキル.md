# 執筆に使うSkills

記事の構成には **writing-discipline**、日本語表現の点検には **natural-japanese**、最終推敲には **yomiyasu** を使う。記事そのものの正しさはスキルやLintに委ねず、[執筆方針](執筆方針.md)と[根拠と更新](根拠と更新.md)に従って確認する。

## skills CLIで導入する

スキルは手動でコピーして管理しない。**[公式skills CLI](https://github.com/vercel-labs/skills)** からプロジェクト単位で導入する。

```bash
bash scripts/install-skills.sh
```

スクリプトは次の2つのソースから3種類をインストールする。

```bash
npx --yes skills@latest add rebuildup/writing-skills --skill writing-discipline --skill natural-japanese --agent codex --agent claude-code --agent opencode --copy --yes
npx --yes skills@latest add nanaism/yomiyasu --skill yomiyasu --agent codex --agent claude-code --agent opencode --copy --yes
```

**対応先**：Codex（`.agents/skills/`）、Claude Code（`.claude/skills/`）、OpenCode（`.opencode/skills/`）。Windowsでもgitのシンボリックリンクを要求しないよう、`--copy`を指定する。複数のコピーは**CLIが管理**し、手で内容を修正しない。

`skills-lock.json`と導入されたスキルはリポジトリへコミットする。更新時は同じコマンドを実行して差分・参照元の版をPRで確認する。公式の `npx skills update` も利用できるが、コピー元と管理範囲を把握してから実行する。

## 執筆工程

1. [writing-discipline](../.agents/skills/writing-discipline/SKILL.md)で読み手が必要な答えと根拠を選ぶ。
2. [natural-japanese](../.agents/skills/natural-japanese/SKILL.md)で初稿の自然さ・読みやすさを確認。
3. [yomiyasu](../.agents/skills/yomiyasu/SKILL.md)で意味を保持して推敲する。
4. タイトル・第一文・各見出しだけを読んでも結論が伝わるか人間の目で確認する。

スキルの出した指摘は編集候補であり、機械的な言い換えで主張を変えてはいけない。

## 検査

```bash
python3 scripts/editorial_check.py
for f in articles/*/article.md; do
  python3 .agents/skills/yomiyasu/scripts/yomiyasu_lint.py --doc-type article "$f"
done
```

GitHub Actionsは導入手順を実行し、Skills配置・Python構文・記事の構造を検証する。リポジトリ内のスキルを無断で直接修正しない。元ソースとライセンスは[writing-skills](https://github.com/rebuildup/writing-skills)、[yomiyasu](https://github.com/nanaism/yomiyasu)を参照。
